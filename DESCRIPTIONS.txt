halcyon -- repository descriptions
==================================

Repository name: halcyon
Image reference: ghcr.io/<owner>/halcyon

All four descriptions are plain text only (GitHub's About field does not

1. -- recommended -------------------------------------------------------

An atomic Linux image that boots into Hyprland with NVIDIA drivers, a
gaming kernel, and nothing left to configure. Rebuilt daily -- calm, by
definition.


2. -- name-forward ------------------------------------------------------

Hyprland, NVIDIA drivers, and a gaming kernel, pinned into one atomic
image. Updates arrive overnight; the sea stays calm. That is what the
name promises, and the image keeps it.


3. -- feature-lead ------------------------------------------------------

Boots straight into Hyprland on an atomic base: NVIDIA drivers, the OGC
gaming kernel, fonts, Flatpaks and dotfiles already in place. Rebuilt
every morning, so nothing is left to configure.


4. -- terse -------------------------------------------------------------

An atomic desktop with the tedium pre-solved. Hyprland, NVIDIA, a gaming
kernel -- all present at first login, refreshed daily, impossible to
drift out of shape. Halcyon days, every day.
